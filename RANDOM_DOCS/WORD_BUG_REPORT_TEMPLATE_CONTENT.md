# HOW TO CREATE THE WORD DOCUMENT

Copy the content from `BUG_REPORT_TEMPLATE.md` into Microsoft Word and format as follows:

## Formatting Instructions:

### Title (First line):
- Font: Arial, 18pt, Bold
- Color: Dark Blue
- Alignment: Center

### Section Headings (e.g., "CLASSIFICATION", "BUG SUMMARY"):
- Font: Arial, 14pt, Bold
- Color: Dark Red
- Background: Light Gray
- Spacing: 12pt before, 6pt after

### Subsection Headings (e.g., "Bug ID:", "Severity Level:"):
- Font: Arial, 12pt, Bold
- Color: Black

### Body Text:
- Font: Calibri, 11pt, Regular
- Color: Black
- Line spacing: 1.15

### Checkboxes:
- Use: Insert → Symbol → ☐ (empty checkbox)
- Use: Insert → Symbol → ☑ (checked checkbox)
- Or use Word's checkbox feature: Developer tab → Checkbox

### Code/Technical Sections:
- Font: Courier New, 10pt
- Background: Light gray
- Border: Thin gray line

### Screenshot Placeholders:
- Insert → Text Box or Table
- Size: 6 inches wide x 4 inches tall
- Border: Dashed gray line
- Center text: "[PASTE SCREENSHOT HERE]"

### Color Coding for Severity:
- S1 - Critical: Red text, red left border (3pt)
- S2 - Major: Orange text, orange left border (3pt)
- S3 - Minor: Yellow background with black text
- S4 - Suggestion: Light blue background with black text

### Page Setup:
- Margins: 1 inch all sides
- Orientation: Portrait
- Page size: A4 or Letter

### Footer:
- Page numbers: Bottom center
- Format: "Page X of Y"

---

## Save As:
- **Template file:** `AIRRVie_Bug_Report_Template.docx`
- **For actual bug reports:** `BUG_[Severity]_[ShortTitle]_[Name]_[Date].docx`
