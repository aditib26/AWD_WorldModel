# AIRRVie Field Test - Google Form Structure

## Instructions for Creating the Form

1. Go to **forms.google.com**
2. Click **"+ Blank"** to create new form
3. Title: **"AIRRVie Field Test Feedback - Extension Officers"**
4. Description: Copy the text below

## How to Use This Form

### For You (Test Coordinator):

1. **Create the form:**
   - Follow structure above
   - Copy/paste questions exactly
   - Configure all settings

2. **Test the form yourself:**
   - Fill it out once to check flow
   - Verify all questions display correctly
   - Check response spreadsheet is created

3. **Share with testers:**
   - Click "Send" button
   - Copy link
   - Send to 10 extension officers via email/WhatsApp

4. **Monitor responses:**
   - View → Responses tab
   - See responses in real-time
   - Export to Google Sheets for analysis

### For Testers:

1. Receive form link
2. Complete app testing first (use Field Test Guide)
3. Fill out form (15-20 minutes)
4. Upload screenshots if bugs found
5. Submit

### Automatic Features:

- ✅ Responses auto-saved to Google Sheets
- ✅ Real-time response tracking
- ✅ Automatic charts and graphs
- ✅ Can export to Excel anytime
- ✅ Can view individual or summary responses

1. Click **Responses** → Green Sheets icon

3. Use pivot tables and charts
4. Calculate statistics
5. Filter and sort responses

## Tips for Better Responses

**Add these tips in form description or confirmation:**

```
Tips for Helpful Feedback:
- Be specific: Instead of "AI is bad," say "AI gave wrong fertilizer amount for my area"
- Include examples: Copy/paste actual AI responses if possible
- Think like a farmer: Would farmers understand this? Find it useful?
- Test thoroughly: Spend at least 1 hour testing before submitting feedback
- Be honest: We want to know what doesn't work so we can fix it
```
